## Description
(Max 4000 characters)

```
PerfScopeX is a powerful system performance monitor that gives you real-time visibility into your iPhone's CPU, memory, network, and storage. Visualize everything through beautiful charts, and check your iPhone's status at a glance from Dynamic Island or your home screen widget.

【Key Features】

▶ Real-Time Performance Monitoring
• CPU Usage — Detailed breakdown of user, system, and idle activity
• Memory Usage — Analyze used, free, active, and compressed memory
• Network Speed — Live download and upload speed tracking
• Storage — Instantly see used and available space

▶ Beautiful Real-Time Charts
Smooth animated charts powered by the Swift Charts framework let you intuitively track performance over time. Modern visual design with gradients and shadows.

▶ Home Screen Widgets (3 Sizes)
• Small: CPU usage with mini chart
• Medium: CPU + memory + chart
• Large: CPU + memory + network + storage — all at once
Auto-refreshes every minute so you always have the latest status without opening the app.

▶ Dynamic Island & Live Activities (iPhone 14 Pro and later)
Display CPU, memory, and network info live in the Dynamic Island. Stay informed even when the app is in the background. Also supported on the Lock Screen.

▶ Smart Threshold Alerts
Get notified instantly when metrics exceed your set thresholds:
• CPU usage over 80%
• Memory usage over 85%
• Storage usage over 90%
(All thresholds are fully customizable)

▶ Flexible Customization
• Toggle individual metrics on/off
• Adjust refresh rate (0.5s – 5s)
• Set chart history length
• Sensory (haptic) feedback support

【Privacy & Security】
Uses only standard iOS APIs — no jailbreak required. No personal data is collected or sent to external servers. Runs safely within the iOS sandbox.

【Requirements】
• iOS 17.0 or later
• iPhone
```
